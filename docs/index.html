Drea.

A minimalist, terminal-based AI agent harness that lives in your shell. Written in Go with zero dependencies — no Node, no Python, no runtimes to install. It drives any OpenAI-compatible model through a reason–act loop with a small, auditable set of tools, and it prompts before every command and file write.

git clone https://github.com/dreaagent/drea.git && cd drea && go build -o drea ./cmd/drea

// why drea

Small enough to own.

No runtimes to install. No package managers to feed. No ghosts living in your shell. Just one codebase you can read, build, and run yourself.

01

Zero dependencies

No Node.js. No Python. No npm install, no pip, no venv. Go's standard library does everything — HTTP, TLS, JSON and SSE streaming — so go.mod lists no requires.

02

One static binary

Fast startup, low memory, nothing to install at runtime. One file you can move, copy, ship, or forget about once you've built it.

03

Confined by default

Every file, search and command tool is restricted to a single workspace root; path traversal outside it is rejected.

04

Approval by default

Commands and file writes require your confirmation unless you pass --auto. Writes and edits are shown as a coloured diff before they are applied.

05

Live file writes

When the model writes or edits a file, the streamed content is rendered as a rolling tail of the last 10 lines — you watch the file being built.

06

Any model, any endpoint

Drives any OpenAI-compatible model — hosted or local, keyed or keyless. JSON-mode tool calling is on by default so even small models work.

// install

Build from source.

There are no pre-built binaries yet. The only way to run Drea today is to compile it yourself — which is also the best way to trust it.

Source release

Download the latest tagged source archive, extract it, and build with Go.

curl -L https://github.com/dreaagent/drea/archive/refs/tags/v0.1.0-alpha.1.tar.gz | tar xz && cd drea-0.1.0-alpha.1 && go build ./cmd/drea

Build & install

Requires Go 1.19+. Build the binary and optionally put it on your PATH.

go build -o drea ./cmd/drea

Clone & build

Full control. Clone the repository, read the code, and build the latest commit.

git clone https://github.com/dreaagent/drea.git && cd drea && go build -o drea ./cmd/drea

Drea has been tested on Linux (Go 1.19, Debian 12). Set DREA_API_KEY (or OPENAI_API_KEY) and run ./drea in any project — or point it at a local, keyless endpoint with --base-url. The API key stays out of your shell history and is never logged. No config files, no setup wizard, no ceremony.
